## 待完成（按优先级）

### 优先级 1：OSF Preprints DOI
- **操作**：上传论文 PDF → 获取 DOI
- **平台**：osf.io/preprints
- **费用**：免费
- **时间**：即时（上传即有 DOI）
- **价值**：全球学术界承认的永久优先权证明。DOI 不可删除不可篡改。

### 优先级 2：软件著作权登记
- **操作**：向中国版权保护中心提交申请
- **费用**：¥300 官费（如需代理 +¥500-1000）
- **时间**：30-60 工作日
- **材料**：源码前 30 页 + 后 30 页（共 60 页）、用户手册/设计文档、申请表
- **平台**：http://www.ccopyright.com.cn/
- **注意**：软著保护的是代码实现，不保护思想。但它和 OSF/GitHub 互补——软著保护实现，OSF 声明思想。

### 优先级 3：商标注册
- **类别**：
  - 第 9 类（计算机软件、APP）："Linna""琳娜"
  - 第 42 类（科学技术服务、SaaS）："Linna""琳娜"
  - 建议追加："宇宙之书""Linnaphia"
- **费用**：¥300/类（官费），如需代理 +¥500-1000/类
- **时间**：9-12 个月（形式审查 → 实质审查 → 公告 → 注册）
- **平台**：中国商标局 http://sbj.cnipa.gov.cn/
- **注意**：商标从申请日起算保护，不是从注册日起算。越早申请越好。

### 优先级 4：发明专利申请（可选，预算允许时）
- **名称建议**："一种基于 3D 空间隐喻的个人知识管理系统及方法"
- **费用**：¥5,000-15,000（含代理费 + 官费 + 实质审查费）
- **时间**：2-3 年（申请 → 公开 → 实质审查 → 授权）
- **注意**：
  - 专利要求**绝对新颖性**——申请日之前不能有公开披露
  - ⚠️ 如果你的 OSF 论文和 GitHub 已经公开，**这些内容就不能再申请专利了**
  - 但你可以在论文的基础上增加未公开的技术细节，就增量部分申请专利
  - 建议等有三四个月开发积累后，拿具体的技术实现去申请
  - 申请日即保护起算日（不像商标）

## 关键提醒

1. **OSF 和 GitHub 已经建立了你的在先权利**。如果有人看到你的仓库后抄了你的想法，你的公开时间戳就是底牌。
2. **不需要急着花大钱**。商标和专利可以等产品有了初步形态再做。
3. **不要公开所有技术细节**。GitHub 上放的是设计框架和概念，不要把核心算法、数据模型细节、未来商业方案放上去。
4. **Linnaphia 是个不错的品牌名**，建议在商标注册时同时注册这个拼写。
