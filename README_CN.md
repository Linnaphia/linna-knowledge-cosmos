## 问题

你今天用的每一个 AI 助手都有同一个缺陷：**它不认识你**。

现在的 AI 助手很聪明。但每次对话都从零开始。它们不知道你学过什么、关心什么、之前聊过什么。本应是*你的*助手，却没有关于*你*的记忆。

同时，你保存的内容约 50% 永远不会再打开（UC Berkeley iSchool, 2025）。知识散落在笔记、书签、聊天记录和文件中——存着，但从未活过。

## 解决方案

**Linna** 将三件事组合在一起，此前无人做过：

### 1. 3D 空间宇宙
你的知识不是文件夹树。它是一片星空。每个主题是一颗**星球**，相关主题构成**星系**，知识关联是发光的**连接线**。你是这个宇宙的创造者和主宰者。

> *研究支撑*：3D 空间界面降低认知负荷（Li et al., 2024）。空间记忆组织方式将知识留存提升 14 天以上（Lee & Lee, 2025）。

### 2. 宇宙之书
一个随你一起成长的个人知识库。你保存的每条想法、笔记、洞见，都成为结构化、可检索、有生命的知识系统的一部分——而不是被遗忘的书签。

### 3. 一个真正懂你的 AI
AI 助手不从互联网搜答案。它从**你的**宇宙之书里检索。每个答案都附上来源："根据你 2026 年 3 月关于 React 性能优化的笔记……"

> 这不是聊天机器人。这是*你的* AI，建立在*你的*知识之上。

## 核心设计原则

- **遵循人类操作习惯** — 不发明新的交互范式，所有操作符合用户已有认知
- **高效、简洁、耐用** — 为数十年的知识积累设计，不因数据量增长而退化
- **跨端一致** — 桌面端和手机端共用同一套操作流程
- **研究驱动** — 每个设计决策都有公开发表的 HCI 和认知科学论文支撑

## 系统架构

```
第一层 — 宇宙总览（3D星空）
    │  可旋转/缩放的星空，一眼看到所有知识
    │  点击星球 → 进入第二层
    │
第二层 — 星球目录（结构化列表）
    │  标题 + 摘要 + 时间 + 标签
    │  点击条目 → 进入第三层
    │
第三层 — 内容阅读/编辑
    │  全屏文本，可呼出目录
    │  编辑、标记、关联

全局路径（任何页面均可直达）：
    搜索：Ctrl+K（桌面） / 顶部搜索栏（手机）
    AI 助手：右下角浮球（桌面） / FAB 按钮（手机）
```
